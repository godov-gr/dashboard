# Схема-дашборд

Дашборд в виде современной интерактивной схемы. Вход по логину/паролю, отдельные
аккаунты, у каждого — своя материнская нода. От любой ноды можно рисовать дочерние
и писать в них заметки.

## Возможности
- Регистрация и вход (пароли хранятся в виде хэша, сессии на cookie).
- У каждого аккаунта своя схема, изолированная от других.
- Несколько материнских («корневых») нод на аккаунт: одна создаётся при
  регистрации, ещё можно добавить кнопкой **✚ Материнская** в шапке.
- Дочерние ноды: кнопка **+** на ноде или **+ Дочерняя нода** в редакторе;
  новая нода появляется рядом с родителем (веером вверх/вниз), а не «улетает» вниз.
- Заметки: клик по ноде открывает панель редактирования (заголовок + текст).
  Клик прямо по заголовку ноды сразу выделяет его текст для переименования.
- Жирный текст в заметке: выделите текст в редакторе и нажмите **Ж** (или
  Ctrl+B) — хранится как `**жирный**`, на ноде рендерится настоящим bold.
- Перетаскивание нод, панорамирование фона, зум колесом (от **1%** до 250%),
  кнопка «Центр».
- Мультивыбор: Shift+клик по ноде добавляет её к выделению, Shift+тянуть по
  пустому фону — выделение рамкой; выделенные ноды двигаются вместе, вверху
  появляется панель массового удаления.
- Зоны — области на холсте (кнопка **▭ Зона**, нарисовать прямоугольник):
  ноды, оказавшиеся внутри границ, «живут» в зоне и переезжают вместе с ней
  при перетаскивании за её заголовок.
- Связи между нодами помимо дерева родитель → потомок (кнопка **🔗 Связь**,
  клик по двум нодам подряд) — например, общая дочерняя нода у нескольких
  родителей. Линии — пунктирные, клик по линии удаляет связь.
- Линии от родителя к потомку идут по кратчайшей прямой от границы одной
  ноды до границы другой (без изломов).
- Поиск по заголовку и содержимому нод (шапка), Enter — перейти к первому
  совпадению; найденные ноды подсвечиваются, остальные гаснут.
- Экспорт ветки (нода + все её потомки, со связями) в JSON-файл — кнопка
  **⭳ Экспорт** в редакторе ноды.
- Нода целиком заливается цветом: палитра + произвольный цвет (🎨); текст сам
  подстраивается (тёмный на светлом фоне); заголовок отцентрирован.
- Ширина ноды подстраивается под длину заголовка автоматически (если размер
  не задан вручную); высота — под текст. Ноду можно растянуть за правый
  нижний уголок или задать размер числами в редакторе (↺ — сброс к авто).
- Участники: к ноде можно прикрепить других пользователей (блок «Участники»
  в редакторе), на ноде показываются их аватарки.
- Файлы: к ноде можно прикрепить файл/фото (блок «Файлы» в редакторе,
  до 20 МБ); хранятся на диске в `uploads/`, доступны только владельцу ноды.
- Автосохранение всех изменений на сервере (с задержкой ~0.45 c).

## Стек
- Бэкенд: Python + Flask, база — SQLite (файл `data.db`, создаётся сам).
- Фронтенд: ванильный JS + CSS, без сборки.

## Локальный запуск
```
cd dashboard
python app.py
```
Затем открыть http://127.0.0.1:5000 — сначала регистрация, потом вход.

Тестовые аккаунты создаются автоматически при первом запуске:
`admin` / `admin1234` и `test` / `test1234`.

В Windows можно просто дважды кликнуть `run.bat`.

Если Flask не установлен:
```
pip install -r requirements.txt
```

## Управление на холсте
| Действие                          | Как                                             |
|------------------------------------|--------------------------------------------------|
| Переместить холст                 | тянуть пустой фон                                |
| Зум (1%–250%)                      | колесо мыши                                      |
| Выбрать ноду                      | клик                                             |

| Выделить рамкой несколько нод     | Shift+тянуть по пустому фону                     |
| Переместить ноду(ы)               | тянуть ноду (выделенные двигаются вместе)        |
| Открыть заметку/редактор          | клик по ноде (без перетаскивания)                |
| Переименовать ноду                | клик по заголовку ноды — текст сразу выделен     |
| Добавить дочернюю ноду            | кнопка **+** на ноде                             |
| Добавить материнскую ноду         | кнопка **✚ Материнская** в шапке                 |
| Нарисовать зону                   | кнопка **▭ Зона**, затем тянуть по пустому фону  |
| Связать две ноды                  | кнопка **🔗 Связь**, клик по первой, потом второй |
| Удалить связь                     | клик по пунктирной линии связи                   |
| Удалить ноду (и потомков)         | кнопка «Удалить» в редакторе                     |
| Удалить несколько нод             | выделить, кнопка «Удалить выделенные»            |
| Экспорт ветки в JSON               | кнопка «⭳ Экспорт» в редакторе                   |
| Поиск по нодам                    | поле поиска в шапке, Enter — перейти к находке   |
| Центрировать схему                | кнопка «Центр» вверху                            |

## Деплой на сервер (позже)
1. На сервере: `pip install -r requirements.txt gunicorn`
2. Задать секрет: `export DASHBOARD_SECRET="длинная-случайная-строка"`
3. Запуск: `gunicorn -w 3 -b 0.0.0.0:8000 app:app`
4. Поставить nginx как reverse-proxy и HTTPS (для secure-cookie).

> Для продакшена задайте `DASHBOARD_SECRET` через переменную окружения —
> без него используется небезопасный ключ по умолчанию. При HTTPS включите
> `SESSION_COOKIE_SECURE=True` в `app.config`.
